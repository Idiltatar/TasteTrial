# TasteTrial

TasteTrial is a Flutter app concept for exploring travel and local recommendation content.

The project is kept as part of my portfolio to show mobile app planning and recommendation-focused product thinking.

## Planned Tech Stack

- Flutter
- Dart
- Mobile-first UI

## Intended Features

- Travel and place recommendations
- Simple browsing experience for local options
- Mobile-friendly interface
- Recommendation-focused content structure

## Project Status

This repository currently contains a lightweight project overview. The implementation can be expanded with Flutter source files, screenshots and setup instructions in a future update.
